# Travel companion  App 📱

## Overview
This Android application helps international travellers convert essential
values. The app must support conversions for Currency, Fuel Efficiency, and Liquid Volume.t 

## Features
- Convert between different Currency -  AUD, EUR, JPY, GBP
- Convert between Celsius, Fahrenheit, and Kelvin
- Dropdown selection using Spinners
- User input 
- Clean and responsive UI

## Technologies Used
- Java (Android)
- Android Studio
- XML (UI Design)

## Project Structure
- `MainActivity.java` → Handles logic and user interaction
- `activity_main.xml` → UI layout
- `strings.xml` → Stores dropdown values

## ▶How to Run
1. Clone the repository
2. Open in Android Studio
3. Click Run ▶️
